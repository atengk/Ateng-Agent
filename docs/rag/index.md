# RAG 知识库检索增强

| 属性 | 详情 |
| :--- | :--- |
| **模块** | 检索增强生成 (RAG) |
| **状态** | 规划建设中 |
| **维护者** | Ateng |

本模块专注于大模型外挂知识库（RAG）与向量数据库的工程化落地：

- **向量数据库**：Chroma、Milvus、Qdrant 等向量存储集成与索引调优
- **文档预处理**：PDF/Markdown 多格式智能切块（Chunking）与元数据提取
- **检索增强优化**：多路召回（Dense + Sparse）、重排序（Rerank）与上下文压缩
