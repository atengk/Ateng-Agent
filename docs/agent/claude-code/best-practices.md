## 1. 规范治理驱动 (CLAUDE.md)

Claude Code 原生支持通过项目根目录的 `CLAUDE.md` 获取项目的最高意志和工程守则。

### 推荐配置项
- **常用构建命令**：明确告知编译、格式化、单测指令（如 `pnpm test`、`pnpm build`）；
- **架构决策与分层**：告知其核心业务逻辑目录，严禁越级调用；
- **Git 提交红线**：约束其修改代码后交由开发者人工审核，不自动 push。

## 2. 复杂排障自愈心法

面对复杂长堆栈报错时，指导 Claude Code 开展三阶段诊断：
1. **重现（Reproduce）**：首先定位并运行最小可复现用例；
2. **假设与验证（Hypothesis）**：审查核心代码分支，给出最可能的缺陷成因；
3. **修复与回归（Fix & Regression）**：实施最小范围代码补丁，并执行端到端回归校验。
