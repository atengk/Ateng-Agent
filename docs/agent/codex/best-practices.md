## 1. 高效提示词心法 (Prompt Patterns)

在使用 Codex 这类轻量级快速模型时，清晰的结构化输入比冗长散文更能产出确定性代码：

1. **三段式角色约束**：明确**输入现状 (Given)**、**期望动作 (When)** 与 **验收标准 (Then)**；
2. **负面清单声明 (Negative Constraints)**：显式告知智能体“不要修改已有公共接口签名”、“不要引入第三方未授权库”；
3. **锚点式局部重构**：提供上下文周围的锚点行号，避免全文件重写带来的大面积 Diff 污染。

## 2. 局部代码无损重构范例
