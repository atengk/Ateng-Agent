# MCP 协议生态

| 属性 | 详情 |
| :--- | :--- |
| **模块** | Model Context Protocol 协议生态 |
| **状态** | 规划建设中 |
| **维护者** | Ateng |

本模块专注于 Model Context Protocol（MCP）协议的标准接入、生态服务部署与自研实践：

- **数据库服务集成**：MySQL、PostgreSQL、Redis 等安全访问配置
- **研发工具打通**：Git、GitHub、Gitee、IDE 深度联动
- **办公与生产力扩展**：飞书、邮件推送、定时任务等协同集成
- **自研 MCP Server**：基于 TypeScript / Python 开发企业私有 MCP 扩展
